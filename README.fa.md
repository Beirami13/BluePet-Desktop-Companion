# Blue Pet

یک پت کوچک روی دسکتاپ. نشانگر موس رو دنبال می‌کنه، حالت‌های مختلف داره، با گذشت زمان بزرگ می‌شه، **حرف می‌زنه و گوش می‌ده** (فارسی یا انگلیسی، آنلاین یا آفلاین) و یک **میز دانشجو** داره: یادداشت، وظایف، تایمر مطالعه، ماشین‌حساب و تاریخچهٔ کلیپ‌بورد، که همه‌چیز روی خود کامپیوتر ذخیره می‌شه.

[English](README.md)

## قابلیت‌ها

- **پتی با احساسات.** شاد، ناراحت، خجالتی، کنجکاو، خواب‌آلود، عصبانی... به موس و کلیک واکنش نشون می‌ده (زیاد کلیک کنی اذیت می‌شه)، شب‌ها خوابش میاد و تو رو بین دفعه‌ها یادش می‌مونه.
- **بزرگ می‌شه.** بچه، نوجوان، بزرگ. شخصیتش (وابسته، دوستانه، خنثی، دور) به وقتی که باهاش می‌گذرونی بستگی داره.
- **کنترل صوتی فارسی و انگلیسی.** همیشه گوش می‌ده، بدون دکمه. بگو «بیا اینجا»، «بخواب»، «جوک بگو»...
- **بدون اینترنت هم کار می‌کنه.** تشخیص گفتار آفلاین ([Vosk](https://alphacephei.com/vosk/)) و صدای آفلاین ([Piper](https://github.com/rhasspy/piper)).
- **میز دانشجو** (کلید **P**): یادداشت، وظایف، ردیاب مطالعه، ماشین‌حساب، کلیپ‌بورد. همه با صدا هم کنترل می‌شن.
- **جواب می‌ده.** وقتی بگی ناراحتی، خسته‌ای، استرس داری یا خوشحالی واکنش نشون می‌ده، جوک و نکته می‌گه و بازی‌های کوچیک انجام می‌ده.

## نصب

پایتون ۳.۱۰ یا بالاتر لازمه.

```bash
git clone <آدرس-مخزن>
cd BluePet
python -m venv .venv
.venv\Scripts\activate           # ویندوز   (مک و لینوکس: source .venv/bin/activate)
pip install -r requirements.txt
python Main.py
```

روی لینوکس برای میکروفون ممکنه PortAudio هم لازم بشه: `sudo apt install libportaudio2`.

روی ویندوز ساخته و استفاده شده. مک و لینوکس باید کار کنن ولی کمتر تست شدن.

### صدا بدون اینترنت (اختیاری، یک بار دانلود)

```bash
python download_models.py
```

این دستور مدل‌های آفلاین رو توی `models/` دانلود می‌کنه (حدود ۱۰۰ مگابایت): تشخیص فارسی و انگلیسی و یک صدای طبیعی انگلیسی برای پت. بعدش پت بدون هیچ اتصالی کار می‌کنه.

اگه شبکه‌ات سایت‌های دانلود رو مسدود کرده، از VPN یا پروکسی استفاده کن (`set HTTPS_PROXY=http://127.0.0.1:PORT`) یا فایل‌ها رو خودت دانلود و نصب کن:

| فایل | نصب |
|---|---|
| `vosk-model-small-en-us-0.15.zip` | `python download_models.py en path\to\file.zip` |
| `vosk-model-small-fa-0.5.zip` | `python download_models.py fa path\to\file.zip` |
| `en_US-lessac-medium.onnx` و `.onnx.json` | `python download_models.py piper file.onnx file.onnx.json` |

منبع: <https://alphacephei.com/vosk/models> و <https://huggingface.co/rhasspy/piper-voices>.
یا دستی کپی کن:

```
models/en/        پوشهٔ بازشدهٔ مدل Vosk (شامل am/ conf/ graph/ ...)
models/fa/
models/piper/en_US-lessac-medium.onnx
models/piper/en_US-lessac-medium.onnx.json
```

## استفاده

می‌تونی اول اسمش رو بگی («هی بلو ...») ولی لازم نیست (مگه اینکه `REQUIRE_WAKE_WORD` روشن باشه).

| بگو | چی می‌شه |
|---|---|
| بیا اینجا / برو | میاد پیش موس / می‌ره خونه |
| بخواب / بیدار شو | می‌خوابه / بیدار می‌شه |
| حالت چطوره، ساعت چنده، تو کی هستی | گپ کوتاه |
| بخند، گریه کن، عصبانی شو... | اون حالت رو نشون می‌ده |
| کمک | می‌گه چی بلده |
| ناراحتم، خسته‌ام، امتحان دارم، انگیزه بده، حوصله‌ام سر رفته | دلداری و تشویق |
| جوک بگو، یه چیز جالب بگو، امروز چه روزیه | سرگرمی |
| سکه بنداز، تاس بنداز، سنگ کاغذ قیچی، حدس عدد، بازی کنیم | بازی |

اگه حرفی بزنی که نشون بده واقعاً حالت بده، پت مهربون جواب می‌ده و پیشنهاد می‌کنه با کسی که بهش اعتماد داری یا یه متخصص حرف بزنی.

کیبورد (وقتی پنجرهٔ پت فوکس داره): `S` وضعیت، `W` اذیت کردن، `2`-`9` و `0` و `Q` و `E` نمایش حالت‌ها (برای تست).

## میز دانشجو

کلید **P** پنل رو باز می‌کنه و **Esc** می‌بنده (یا بگو «میز دانشجو» / «میز رو ببند»). هدر پنل رو بکش تا پنجره جابه‌جا بشه.

| تب | کار | با صدا |
|---|---|---|
| **Notes** | نوشتن، جستجو و ویرایش یادداشت. `Ctrl+Enter` ذخیره می‌کنه. | «یادداشت کن خرید نان» |
| **Tasks** | وظایف با مهلت اختیاری. عقب‌افتاده‌ها و امروزی‌ها مشخصن. | «تسک جدید خرید نان»، «تسک هام» |
| **Study** | تایمر مطالعه با موضوع، مجموع امروز، نمودار ۷ روز. تایمر می‌تونه روی پت نشون داده بشه. | «شروع مطالعه ریاضی»، «مطالعه رو تموم کن»، «شروع تمرکز بیست دقیقه»، «چقدر مطالعه کردم» |
| **Calc** | ماشین‌حساب با کیبورد. تحلیل امن، بدون `eval`. توابع مثلثاتی رادیان می‌گیرن: `sin(radians(30))`. | «حساب کن دو به توان سه» |
| **Clipboard** | تاریخچهٔ متن‌های کپی‌شده. روی یک مورد کلیک کن تا دوباره کپی بشه. حذف، پاک‌کردن همه، یا مکث ضبط. | «کلیپ بورد» |

وقتی با صدا مطالعه رو شروع کنی، پت می‌پرسه **«می‌خوای تایمر رو نشونت بدم؟»**. با آره یا نه جواب بده. «تایمر رو نشون بده» هم هر وقت کار می‌کنه.

تاریخچهٔ کلیپ‌بورد چیزی رو که مدیر رمز محرمانه علامت بزنه ثبت نمی‌کنه، ولی بقیهٔ چیزهای کپی‌شده رو تا وقتی روشنه ثبت می‌کنه. قبل از کپی متن حساس مکثش کن.

## تنظیمات

تنظیمات صدا بالای `voice.py` هستن:

| تنظیم | معنی |
|---|---|
| `VOICE_LANGUAGE` | `"en"` یا `"fa"` |
| `RECOGNITION_MODE` | `"auto"` آنلاین Google و آفلاین Vosk؛ `"offline"` همیشه Vosk؛ `"online"` فقط Google |
| `TTS_MODE` | `"auto"` آنلاین صدای Edge و آفلاین صدای آفلاین؛ `"offline"`؛ `"online"` |
| `OFFLINE_PITCH` | زیر و بمی صدای آفلاین. `1.0` معمولی، `1.25` پیش‌فرض، `1.4` جیرجیری |
| `MIN_THRESHOLD`، `SILENCE_END` | حساسیت میکروفون و مکثی که جمله رو تموم می‌کنه |

تنظیمات رفتاری بالای `web/script.js` هستن: `SHOW_BUBBLES`، `VOICE_REPLY`، `SHOW_HEARD`، `REQUIRE_WAKE_WORD`، `REPLY_TO_UNKNOWN` و `STAGES`.

## ساختار پروژه

```
Main.py            پنجره، پل پایتون <-> جاوااسکریپت، دیدبان کلیپ‌بورد
voice.py           میکروفون، تشخیص گفتار (آنلاین و آفلاین)، صدای پت
offline_tools.py   ابزارهای SQLite: یادداشت، وظایف، مطالعه، ماشین‌حساب، کلیپ‌بورد
download_models.py دانلود و نصب مدل‌های صدای آفلاین
web/               رابط: index.html، style.css، script.js
data/              دیتابیس (خودکار ساخته می‌شه)
models/            مدل‌های صدای آفلاین (بعد از download_models.py)
```

## داده‌های تو

- یادداشت‌ها، وظایف، جلسه‌های مطالعه و کلیپ‌بورد: `data/bluepet.db` (SQLite، از کامپیوتر تو بیرون نمی‌ره).
- حالت و رشد و پیوند پت: `pet_state.json`.
- هر دو توسط git نادیده گرفته می‌شن. اگه براشون ارزش قائلی نسخهٔ پشتیبان بگیر.
- تایمر مطالعه با بستن برنامه متوقف می‌شه. اگه برنامه کشته بشه، تایمر در آخرین ضربان (هر ۲۰ ثانیه) تموم می‌شه.

صدای آنلاین جمله‌هات رو برای Google (تشخیص) و Microsoft (صدای Edge) می‌فرسته. برای اینکه همه‌چیز روی کامپیوترت بمونه `RECOGNITION_MODE = "offline"` و `TTS_MODE = "offline"` بذار.

## عیب‌یابی

- **پت صدام رو نمی‌شنوه.** پیام‌های `[voice]` توی ترمینال رو ببین. اجازهٔ میکروفون رو برای ترمینال/IDE بده. `MIN_THRESHOLD` رو کم کن یا `DEBUG_LEVELS = True` بذار.
- **«No internet, and no offline voice model yet».** `python download_models.py` رو اجرا کن.
- **پت صدا نمی‌ده.** مطمئن شو `edge-tts` یا `piper-tts` (یا `pyttsx3`) نصبه. صدای آفلاین فارسی نیست مگه اینکه سیستمت داشته باشه؛ جواب‌ها باز هم توی حباب نشون داده می‌شن.
- **`pip install piper-tts` خطا می‌ده.** به نسخهٔ پایتونت بستگی داره. پت به صدای سیستم (`pyttsx3`) برمی‌گرده.
- **صدای آفلاین خیلی بم یا زیره.** `OFFLINE_PITCH` رو در `voice.py` عوض کن.
